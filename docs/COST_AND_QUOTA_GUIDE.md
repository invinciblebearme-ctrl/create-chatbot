# 무료 사용량 및 비용 관리 설명서 (Cost & Quota Policy)

CREATE AI 수업 도우미는 **외부 유료 API(OpenAI 등), 유료 벡터 DB, 유료 SaaS 구독 없이 100% Cloudflare 무료 티어 범위 내에서 운영**할 수 있도록 설계되었습니다.

---

## 1. Cloudflare 무료 티어 현황 및 정책

| 항목 | Cloudflare Workers 무료 한도 | CREATE 챗봇 자체 방어 조치 |
| :--- | :--- | :--- |
| **Workers AI** | 일일 10,000 뉴런(Neurons) 무료 | - 기본 모드를 **무료 자료 검색형**으로 운영<br>- 일일 250회 초과 시 검색 모드로 자동 전환<br>- 동일 질문 10분 메모리 캐시<br>- 최대 컨텍스트 5개 청크(3,000자) 제한 |
| **Cloudflare D1** | 일일 읽기 500만 행 / 쓰기 10만 행 무료 | - 한국어 바이그램 및 FTS 인덱스 최적화<br>- 검색 시 LIMIT 30으로 불필요한 행 스캔 차단 |
| **Cloudflare R2** | 월 저장 10GB / 읽기 1,000만 회 무료 | - 연구학교 PDF 파일(평균 10~30MB 수십 권 수준)에 충분<br>- 브라우저 내 텍스트 추출 후 스트리밍만 담당 |
| **Workers 요청** | 일일 100,000회 무료 | - 클라이언트 IP당 1분 15회 속도 제한 적용 |

## 2. 비용 제로(Cost-Zero) 안전 설계 메커니즘

1. **기본 검색 모드 우선 원칙**:
   - 사용자가 페이지에 진입했을 때 기본 동작 모드는 **D1 기반 무료 자료 검색**입니다.
   - 검색 모드는 Workers AI 모델을 전혀 호출하지 않으므로 AI 뉴런 소비가 0입니다.
2. **Workers AI 선택적 호출**:
   - 교사가 상단의 `AI 요약` 모드를 능동적으로 선택한 경우에만 Workers AI를 호출합니다.
3. **일일 쿼터 보호 및 자동 전환 (Auto-Fallback)**:
   - D1의 `ai_usage` 테이블에 일일 누적 호출 횟수가 기록됩니다.
   - 일일 250회를 초과하거나, AI 호출 중 에러/타임아웃 발생 시 사용자에게 친절한 안내 배너를 띄우고 **즉시 무료 검색 결과 모드로 자동 전환**됩니다.
4. **결제 수단 미등록 시에도 100% 안전**:
   - 유료 카드를 등록하지 않은 무료 계정에서도 안전하게 작동하며, 한도 초과 시 과금이 발생하는 것이 아니라 429 응답 또는 검색 모드로 전환되므로 요금 발생 위험이 전혀 없습니다.
